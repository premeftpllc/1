## 🚨 RISK THRESHOLDS (KPI Triggers)

### Profit Margin Monitoring

```
GREEN ZONE:     24%+ margin
                Action: Continue as planned ✅
                
YELLOW ZONE:    15-23% margin
                Action: Reevaluate sourcing mix ⚠️
                Investigation: Are fees high? Pricing wrong?
                
RED ZONE:       <15% margin
                Action: HALT sourcing 🔴
                Investigation: Fundamental issue with channel
                Decision: Pivot or fix model
```

### Volume Monitoring

```
GREEN ZONE:     3+ items/day
                Status: Healthy pipeline ✅
                Action: Scale and optimize
                
YELLOW ZONE:    2-3 items/day
                Status: Below target ⚠️
                Action: Increase sourcing effort
                
RED ZONE:       <2 items/day
                Status: CRITICAL ❌
                Action: Pivot strategy immediately
                Decision: Try new channels or pause
```

### Return Rate Monitoring

```
GREEN ZONE:     0-2% returns
                Status: Acceptable ✅
                Benchmark: Industry standard
                
YELLOW ZONE:    3-5% returns
                Status: Investigate ⚠️
                Likely cause: Condition mismatch or shipping
                Action: Improve descriptions or packaging
                
RED ZONE:       >8% returns
                Status: CRITICAL ❌
                Action: Critical quality review
                Decision: Pause that product type
```
