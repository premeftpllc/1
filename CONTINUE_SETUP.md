## Working MCP servers

The active config registers ten servers directly (not only through Make), mirroring the set of
connectors already authorized for this account on claude.ai (Airtable, Gmail, Google Calendar,
Google Drive, Make, Notion, Shopify, Slack, Zapier):

- `web-search`: local web search MCP
- `make-custom-mcp`: Make.com hosted MCP bridge — advertises a curated ~42-tool subset by
  default (Make has 146+ total, which alone was ~40k prompt tokens and can exceed a smaller
  model's context window). Edit `.continue/mcp-tool-filters.json` to change the subset, or set
  `MAKE_MCP_TOOL_MODE=all` in the environment to get every tool back for a session. Calls to a
  filtered-out tool still work if something names one explicitly — only the advertised list
  shrinks.
- `notion`: local Notion bridge
- `airtable`: direct Airtable MCP (blocked on API quota — see Known external limits)
- `slack`: direct Slack MCP, launched via `web-search-mcp/scripts/slack-mcp-launcher.js`
- `gmail`: direct Gmail MCP (OAuth2), launched via `.continue/mcp-gmail-launcher.js`
- `google-calendar`: direct Calendar MCP (`@cocal/google-calendar-mcp`), launched via
  `.continue/mcp-calendar-launcher.js` — reuses the same `gcp-oauth.keys.json` as Gmail
- `google-drive`: direct Drive MCP (`@piotr-agier/google-drive-mcp`), launched via
  `.continue/mcp-drive-launcher.js` — also reuses the shared Google OAuth client
- `shopify`: direct Shopify MCP (`shopify-mcp`), launched via
  `.continue/mcp-shopify-launcher.js`, needs its own store credentials
- `zapier`: bridge to Zapier's hosted MCP (`mcp.zapier.com`), launched via
  `.continue/mcp-zapier-bridge.mjs`, needs a per-account URL from Zapier

Slack, Gmail, Calendar, Drive, Shopify, and Zapier all run as direct MCP servers using the
credentials in `.continue/.env.local` — they are not routed through Make. Make additionally
exposes whatever scenarios/connections are configured on the Make side via `make-custom-mcp`.
There's no local equivalent registered yet for the claude.ai Google_Calendar/Drive-adjacent Claude
Docs connector or Canva (Canva isn't authorized on claude.ai either).

## Known external limits

- Airtable monthly API limits cannot be bypassed locally.
- Slack requires a real bot token beginning with `xoxb-` and appropriate scopes.
- Gmail, Calendar, and Drive require Google OAuth2; an API key alone cannot access this data.
  Calendar and Drive share the same OAuth client as Gmail but each stores its own token/consent
  state, so each server needs the one-time browser authorization run separately.
- Shopify requires a custom app created in the target store's admin (static access token or
  Dev Dashboard client credentials) — there is no way to generate this without store access.
- Zapier's hosted MCP is authorized per-account at https://mcp.zapier.com/; the URL it gives you
  is the credential and can't be derived locally.
- Make connection creation requires an authenticated Make account and must be completed in Make.
