## SECTION 3: ARBITRAGE INTEGRATION STRATEGY

### 3.1 Efficient Product Listing for Sourced Items

**Workflow for Below-Retail Sourcing (Pathway 1):**

#### Step 1: Source Identification (Daily, 30 min)
```
Activity: Monitor StockX "Below Retail" filter
Criteria:
- 40%+ discount from retail
- High-demand categories (sneakers, accessories)
- $50+ profit margin potential
- Items in original packaging preferred

Time: 10 AM ET daily
Tools: StockX app + browser bookmarks
Output: Screenshot + notes in PREMEFTP_ARBITRAGE_LOG.md
```

#### Step 2: Rapid Valuation (5 min per item)
```
Calculate Profit:
1. Note StockX price: e.g., $85
2. Research retail/market price: e.g., $130
3. Apply formula:
   - Costs: Shopify fee (2.9%+$0.30) + payment (2%) + shipping ($8) = ~$11
   - Profit = $130 - $85 - $11 = $34/unit
4. If profit > $30: PROCEED to purchase

Decision Matrix:
Profit > $50:     BUY IMMEDIATELY (high confidence)
Profit $30-50:    BUY if item is trending
Profit < $30:     SKIP (margin too thin)
```

#### Step 3: Purchase & Fulfillment (24-48 hours)
```
1. Purchase from StockX
2. Receive item at warehouse (1-2 weeks typical)
3. Quality check + authentication
4. Create Shopify product listing
5. Update inventory + activate product
6. Ship to customer when ordered
```

#### Step 4: Product Creation Template
```markdown
**Title:** [Brand] [Item Type] [Color/Size] [Condition]
Example: Supreme Arabic Logo Hooded Sweatshirt - Black - New

**Description:**
- Condition: [New/Like New/Excellent/Good]
- Size: [S/M/L/XL/One Size]
- Material: [e.g., 100% cotton]
- Sourced from: [StockX/Retail]
- Authentication: ✓ Verified
- Shipping: [Flat rate + processing time]

**Tags:** arbitrage, below-retail, limited-edition, [season], [brand]
**Collection:** Arbitrage_Clearance
**Price:** [Calculated from formula above]
```

**Basic Formula:**
```
Acquisition Cost (Sourced Price)    $85.00
+ Shopify Fee (2.9% + $0.30)        $2.77
+ Payment Processing (2%)           $1.70
+ Shipping/Packaging (avg)          $8.00

─────────────────────────────────────
Subtotal Costs                      $102.15

Target Margin (30-40%)              $30-40
─────────────────────────────────────
RETAIL PRICE (Before Rounding)      $132-142

FINAL RETAIL PRICE (Rounded)        $139.99
─────────────────────────────────────
Actual Profit per Unit              $37-42
```

### 8.2 Dynamic Pricing by Category

**Supreme Apparel (High Demand):**
```
Margin Target: 35-40%
Pricing: Cost × 1.5 (or retail equivalent, whichever is higher)
Example: $60 cost → $90-110 retail
```

**Collectibles (Limited Supply):**
```
Margin Target: 25-35% (lower due to rarity premium)
Pricing: Market rate - 5-10% discount from competitor listings
Example: $200 market rate → $185-195 retail
```

**Sneakers/Footwear (High Volume, Thin Margin):**
```
Margin Target: 20-25% (high volume justifies lower margin)
Pricing: Cost × 1.30-1.35
Example: $100 cost → $130-135 retail
```
