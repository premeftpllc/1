## Research Methodology

### Path 1: Drop Tracker Linkage (Per Item: 10 minutes)
1. **Release Date Research** (5 min)
   - Search Supreme archives for exact release
   - Cross-reference Grailed historical listings
   - Verify against StockX release calendars
   - Look for Supreme community databases

2. **Drop Context Capture** (3 min)
   - Seasonal classification (SS/FW + year)
   - Collaboration status (solo release or collab)
   - Release region (US/EU/JP)
   - Rarity classification (general/limited/exclusive)

3. **Retail Price Validation** (2 min)
   - Capture verified MSRP
   - Source: official Supreme, community consensus
   - Note currency and any regional differences

### Path 2: Market Evidence Collection (Per Item: 15 minutes)

1. **StockX Current Data** (5 min)
   - Search by product name + size/variant
   - Record: Current bid, Current ask, Last sale price
   - Note: Product ID + variant ID if available
   - Volume: 30-day transaction count

2. **Grailed Market Analysis** (5 min)
   - Search for active listings
   - Review sold listings (last 30 days)
   - Calculate average sold price
   - Track listing velocity (days to sell)
   - Note: Condition variance (new, like new, good)

3. **eBay Historical Sales** (3 min)
   - Search completed auctions
   - Average realized price (last 30 days)
   - Transaction frequency
   - Estimated condition from descriptions

4. **Evidence Quality Scoring** (2 min)
   - 5: Real-time data (StockX 100+ sales, 7-day)
   - 4: Recent data (Grailed/eBay 50-100 sales, within 7 days)
   - 3: Moderate data (20-50 sales, within 30 days)
   - 2: Aged data (<20 sales, 30-90 days old)
   - 1: Historical only, no recent activity
